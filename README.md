# TURBA

**Geotechnical engineering skills for AI agents.** *Turba* is Latin for a crowd, and the Arabic *turba* (تربة) means soil.

TURBA is an open collection of [Agent Skills](https://agentskills.io) (`SKILL.md` format) that teach an AI agent how a geotechnical engineer works: build the ground model first, never invent soil parameters, name the standard, check orders of magnitude, and show the calculation chain. Each skill exists in English (`SKILL.md`) and French (`SKILL.fr.md`).

The catalogue is also shown in [GEOTEX](https://geotex.asas-ec.ma) (Knowledge > TURBA).

> TURBA helps an engineer; it does not replace one. Every result an agent produces with these skills is a draft that a qualified geotechnical engineer checks and signs.

## Skills

| Skill | Scope |
|---|---|
| [`turba-core`](skills/turba-core) | Shared rules: ground model, units, Eurocode 7 safety formats, checks before issuing, routing. Load first. |
| [`turba-site-investigation`](skills/turba-site-investigation) | Planning and interpreting PMT, SPT, CPT, lab tests; characteristic values; G1/G2 reports (NF P94-500). |
| [`turba-foundations`](skills/turba-foundations) | Footings, rafts, piles (NF P94-261/262), settlement, t-z, negative friction, springs. Script: Ménard settlement. |
| [`turba-retaining-walls`](skills/turba-retaining-walls) | Embedded walls and deep excavations (NF P94-282), anchors, hydraulics, neighbours. |
| [`turba-slope-stability`](skills/turba-slope-stability) | Slopes, back-analysis, EC7 DA3, soil nailing (Clouterre), stabilising piles. Script: Bishop. |
| [`turba-seismic-liquefaction`](skills/turba-seismic-liquefaction) | EC8 and RPS 2011 site classes, liquefaction (Boulanger and Idriss 2014), Mononobe-Okabe. Script: SPT liquefaction. |
| [`turba-ground-improvement`](skills/turba-ground-improvement) | Stone columns, rigid inclusions, drains and preloading, densification, grouting. |

The machine-readable list is [`catalogue.json`](catalogue.json), generated by `tools/build_catalogue.py`.

## Install

**Any agent that supports skills** (Claude Code, Cursor, Codex, and others, through the `skills` CLI):

```bash
npx skills add ask220119/turba
```

**Claude Code plugin:**

```
/plugin marketplace add ask220119/turba
/plugin install turba@turba
```

**Claude.ai / Claude desktop:** download a skill folder as a zip and upload it in Settings > Capabilities > Skills.

**By hand:** copy `skills/<name>/` into `~/.claude/skills/` (or your agent's skills folder).

## Calculation scripts

Some skills ship small, standard-library Python scripts that the agent can run to check a result independently. They are tested against hand calculations in `tests/`:

```bash
pip install pytest
python tools/build_catalogue.py --check   # validate every skill and the catalogue
pytest -q tests                           # reference tests of the scripts
```
